02 / SCIENCE

Euclid and the dark Universe.

Euclid is designed to investigate the geometry and expansion history of the Universe, mapping galaxies and cosmic structure across space and time. Euclid Lab is an educational companion: it helps users explore data products and learn reproducible analysis concepts.

Measurements are exploratory and uncalibrated. This project is not an official ESA/Euclid product or a replacement for the mission science pipeline.

03 / OPEN SOURCE

git clone https://github.com/amurlaniakea/euclid-lab.git
cd euclid-lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -q
streamlit run app.py

04 / EN ESPAÑOL

Explora el universo oscuro.

Euclid Lab es un observatorio digital educativo para explorar imágenes FITS, detectar fuentes astronómicas, realizar fotometría de apertura básica y consultar catálogos FITS. Incluye una interfaz Streamlit en español e inglés.

La detección y la fotometría son aproximaciones exploratorias, no mediciones calibradas ni un sustituto del pipeline científico de Euclid.
